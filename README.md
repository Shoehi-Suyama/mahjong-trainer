# 麻雀 点数計算トレーナー

麻雀の点数計算を練習するための個人用 Web アプリ。牌姿を見て、役・翻・符・点数を素早く判断できるようになることを目的としています。

**公開URL:** https://shoehi-suyama.github.io/mahjong-trainer/

## モード

| モード | 内容 |
|---|---|
| 点数計算問題 | 完成したアガリを見て点数を答える（選択式／数字入力式） |
| 手牌分析問題 | 役・翻・符・点数を個別に回答し、個別に採点 |
| 実戦トレーニング | 配牌からツモ・打牌を繰り返し、アガリで点数計算 |
| 符計算練習 | 手牌の符だけを当てる。内訳を解説 |
| 苦手問題 | 正答率の低い条件を優先して出題 |
| タイムアタック | 60秒で何問正解できるか |
| 点数早見表 | 符 × 翻の一覧（20〜110符、満貫以上） |
| 学習記録 | 正答率・連続正解・カテゴリ別成績（LocalStorage 保存） |

## 対応役

- **1翻**: リーチ / ダブルリーチ / 一発 / 門前清自摸和 / タンヤオ / ピンフ / 役牌 / 一盃口 / 嶺上開花 / 槍槓 / 海底摸月 / 河底撈魚
- **2翻**: 三色同順 / 三色同刻 / 一気通貫 / 対々和 / 三暗刻 / 三槓子 / 混全帯幺九 / 小三元 / 混老頭
- **3翻**: 混一色 / 純全帯幺九 / 二盃口
- **6翻**: 清一色
- **役満**: 四暗刻 / 大三元 / 小四喜 / 大四喜 / 字一色 / 緑一色 / 清老頭 / 四槓子 / 九蓮宝燈 / 国士無双

喰い下がり・副露（Lv.6）・数え役満に対応。連風牌の雀頭符（+4／+2）は設定で切替可能。

## 設計方針

- 牌画像（`src/assets/tiles/IMG_5688.jpeg`）と麻雀ロジックを完全分離
- 点数計算エンジン（`src/core/`）は UI・画像に非依存で、自動テストで既知の正解と照合
- 問題は「正解となるアガリ」から逆算生成し、`analyzeHand` で必ず自己検証してから出題

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 点数計算エンジンの自動テスト
npm run build    # dist/ に本番ビルド
```

`main` ブランチへの push で GitHub Actions が自動的に GitHub Pages へデプロイします。

## 技術スタック

Vite + React + TypeScript / Vitest。外部 UI ライブラリなし。
